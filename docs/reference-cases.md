# Reference comparison: W16×31

Source documents provided by the user, retained separately from this repository: `W16x31 - TEDDS.pdf` and `W16x31 - Risa.pdf`. Source inputs and output should be checked against the original pages before claiming independent verification.

The TEDDS report (pp. 1–4) identifies a simply supported 20 ft W16×31, A992 steel (E = 29,000 ksi, Fy = 50 ksi), 0.2 kip/ft dead load and 0.8 kip/ft live load plus self-weight, and braces at 0, 5, 10, 15 and 20 ft. It reports 0.354 in deflection, 10.3 kip shear, 51.6 kip-ft moment, and ASD capacities 87.5 kip shear and 134.7 kip-ft bending with Cb = 1.061. The source of the deflection difference needs confirmation; shear deformation is a possible explanation, not an established fact.

RISA's detail report (pp. 1–2, 5, 7–8) lists Ix = 375 in⁴, Zx = 54 in³, A = 9.13 in², 5 ft unbraced length, shear 10.311 kip, moment magnitude 51.553 kip-ft, bending allowable 128.769 kip-ft, and shear allowable 87.45 kip. Its detail report alone does not establish global support constraints or loading. The user supplied those model assumptions and reported that switching off RISA's stiffness adjustment changed deflection from approximately 0.427 to 0.341 in. RISA pp. 5–6 state Cb = 1.000, while TEDDS p. 4 states Cb = 1.061. Differences in section data precision also affect the comparison.

For the user-specified 1.031 kip/ft uniform load, closed-form simple-beam results are 10.31 kip per reaction, 51.55 kip-ft peak moment, about 0.3413 in bending deflection at nominal EI and 0.4266 in at 0.8 EI. The app's calculated values depend on the selected section's self-weight and section data. RISA and TEDDS capacity results are reference values, not validation of any unimplemented capacity calculation. AISC 360-16 ASD and AISC Shapes Database edition must be identified separately.

## Implemented flexural-check benchmark

The limited AISC 360-16 ASD major-axis flexural implementation uses compactness checks from Table B4.1b and yield / lateral-torsional buckling from Chapter F2 for compact, doubly symmetric rolled W sections. Each unbraced interval is evaluated with its own maximum moment and allowable strength. Constant Cb = 1 and F1-1 quarter-point Cb are supported. The maximum nominal strength is capped at Fy Zx; the assumed ASD flexural factor is 1.67. Section strength calculations use the nominal E and section properties and do not apply the beam's reduced analysis stiffness. Local-buckling strength for noncompact or slender shapes is not implemented. This check does not establish OSHA scaffold compliance, adequacy of lateral braces or full beam design.

With the rounded W16x31 properties in the mirrored v15 library (ry = 1.17 in, rts = 1.42 in, Sx = 47.2 in³, J = 0.461 in⁴, ho = 15.5 in, Zx = 54 in³), E = 29,000 ksi and Fy = 50 ksi, Lp = 4.132675 ft and Lr = 11.833431 ft. With Lb = 5 ft and Cb = 1.000, Mn = 215.163776 kip-ft and Mn / 1.67 = 128.840584 kip-ft. RISA pp. 5–6 instead show 128.769 kip-ft using more precise internal properties (Sx = 47.17 in³, ry = 1.165 in, rts = 1.425 in, ho = 15.46 in); the small difference is expected and was not fitted away. For the user-specified uniform 1.031 kip/ft load, the interval 5–10 ft gives Cb = 1.061008, nominal strength 225 kip-ft (plastic-moment cap), and allowable strength 134.731 kip-ft, consistent with TEDDS pp. 3–4 within rounding. These are selected reference comparisons, not independent verification of all inputs, limit states, or OSHA requirements.
