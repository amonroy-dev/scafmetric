# AISC W-shape properties

`aisc-w-shapes-v15.json` contains the 283 W shapes in the US customary units columns of the AISC Shapes Database v15.0, preserving the database property names and numeric values. Absent or inapplicable values are omitted. This is the 15th-edition database, not the current 16th edition; verify the selected section and its applicability against the current AISC data before design.

Source: AISC Shapes Database v15.0 workbook, mirrored at [ambaker1/aisc-csv, commit 38d68425](https://github.com/ambaker1/aisc-csv/tree/38d68425df714141465897b885a9e7a208c1161c/v15.0).
