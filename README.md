# Scafmetric — early beam analysis

A preliminary, bending-only, simply supported beam analysis with a landing page. Run `npm start` from this directory and visit the local server; choose Open calculator to begin; run `npm test` for the closed-form benchmarks. Requires Node.js and Python 3; no npm packages are required. The print button opens the browser print dialog, where a PDF can be saved.

The interface supports full-span downward uniform dead and live loads and multiple downward live point loads at specified distances from the left support, and automatically includes self-weight from the selected W shape. It displays elastic reactions, shear, moment and nominal and reduced-EI deflections. Braces are recorded as lateral restraints, not vertical supports. Calculations use Euler–Bernoulli bending; shear deformation is excluded. A 0.80 stiffness factor is the default standalone assumption, not the Direct Analysis Method. Optional AISC 360-16 ASD major-axis bending and shear checks are available for a limited supported range with explicit confirmations. Concentrated-load local web and flange checks, connection, bearing, deflection-limit and scaffold-specific checks and wind/tie calculations are not implemented. No independent OpenSees comparison has been performed. Do not use this as a construction design or an overall adequacy determination.

The section data comes from a mirrored AISC v15 workbook, not directly from AISC; see [source and limitations](public/data/AISC-SOURCE.md). The hash identifies the mirror only; official integrity and redistribution terms have not been independently verified. Compare properties against the official source before use. The user-supplied references and comparison caveats are summarized in [reference cases](docs/reference-cases.md). Further work is required for the full requested calculation and reporting scope.

Firebase sign-in and 14-day trial code is implemented but not connected or verified with a live project; see [Firebase setup](docs/firebase-setup.md). Stripe, pricing and paid subscriptions are not configured; see [Stripe setup requirements](docs/stripe-setup.md). The visual input guide and synchronized diagrams are available in the calculator.

For Vercel, the repository's `vercel.json` runs `npm run build` and publishes `dist/`. The build copies the site and its data into that directory. Set the Vercel project root to the repository root; project-level build or output overrides must agree with these settings.

The optional 4:1 preset and custom safety-factor load comparisons are user-proposed illustrations only, not verified code combinations or member-capacity checks. Service diagrams and deflections remain on the service load. See [scaffold factors and limitations](docs/scaffold-factors.md) before interpreting them.

The supported beam's visual input guide links drawing labels to fields. Its response diagrams use a synchronized cursor, labeled extrema and zero shear, and a downward-positive reduced-EI deflection plot. Curves connect sampled response values; the report uses vector diagrams. The optional safety-factor comparison is separate from the service diagrams. Additional arrangements and full member and scaffold-capacity checks remain unimplemented.
