# Scafmetric — early beam analysis

A preliminary, bending-only, simply supported beam analysis with a landing page. Install dependencies with `npm ci`, then run `npm start` from this directory and visit the local server to preview the static pages. This static preview does not serve the sign-in and project APIs; use a configured deployment or a local API-capable server to run an analysis. Run `npm test` for the closed-form benchmarks and calculation-report checks. Run `npm run visual` for the scaffold builder's headless WebGL walkthrough: it drives the real built page in headless Chrome with a software GL backend, places parts through real pointer and keyboard events, screenshots every step into `.visual/`, and fails if a step changed nothing or the canvas came back blank. Run `npm run shots` to retake the landing page's screenshots: it works one example job through the built site in headless Chrome, from the scaffold builder to the printed record, and writes the pictures to `public/marketing/screenshots/`; rerun it when the product's look changes. Requires Node.js and Python 3. Export PDF opens the browser print dialog with a dedicated calculation report.

The interface supports full-span downward uniform dead and live loads and multiple downward point loads with separate dead (D) and live (LL) portions at specified distances from the left support, and automatically includes self-weight from the selected W shape. It displays elastic reactions, shear, moment and nominal and reduced-EI deflections. The screen and the calculation report use pounds and feet (forces in lbs, moments in lb-ft, distributed loads in lb/ft, stresses in psi); deflections and section dimensions are in inches. Braces are recorded as lateral restraints, not vertical supports. Calculations use Euler–Bernoulli bending; shear deformation is excluded. A 0.80 stiffness factor is the default standalone assumption, not the Direct Analysis Method. Optional AISC 360-16 ASD major-axis bending and shear checks are available for a limited supported range with explicit confirmations. Bending covers AISC F2 and F3 (compact webs with compact, noncompact or slender flanges). Every run also checks the adjusted (0.8 EI) service deflection against a selectable limit (L/240 by default; L/360 and L/180 available); a beam that passes strength but sags past the limit fails. L/240 is the default criterion for this preliminary support-beam calculation. [OSHA 29 CFR 1926.451(f)(16)](https://www.osha.gov/laws-regs/regulations/standardnumber/1926/1926.451) specifies L/60 for loaded platforms; ANSI/ASSP A10.8-2019 §5.1.1.3 limits platform-unit center deflection under design load to L/60. These provisions do not establish this selected support-beam criterion. A qualified designer must confirm applicable project requirements; see [reference scope](docs/scaffold-factors.md). Concentrated-load local web and flange checks, connection, bearing and scaffold-specific checks and wind/tie calculations are not implemented. No independent OpenSees comparison has been performed. Do not use this as a construction design or an overall adequacy determination.

Complete the guided steps in order; project name and preparer are required, and earlier steps can be reopened for editing. In Step 04, **No lateral bracing** clears interior braces on both flanges and continues to Step 05; end restraints remain assumed. The bracing help is available in the same step.

Changing the main load-type selector to Uniform load or Point load clears the current load schedule and immediately creates one empty row of the selected type. Use **+ Add** to append more rows. Every point load has separate D and LL magnitudes in pounds and its own x distance from the left support. Either portion may be zero; service analysis uses D + LL. The optional comparisons keep point D unchanged and apply SF/1.67 to point LL for bending or SF/1.50 for shear. Top- and bottom-flange brace stations are entered separately immediately below the loads, as comma-separated distances in feet. The end restraints at 0 and the span are included automatically. Under this model's downward loading, the top flange is in compression; only its brace stations define the F2 unbraced intervals. Bottom restraints do not improve top-flange capacity.

The PDF contains the applied-load and bracing schedules, section properties, reaction equilibrium, shear/moment equations, deflection integration, and every evaluated AISC flexural segment and shear check, with numerical substitutions, units and code references. Requested factor comparisons are printed separately, including each point load's D and LL portions and transformed totals. All service diagrams print regardless of the active screen tab. AISC numeric strengths require enabled member checks and confirmed beam assumptions; otherwise the report clearly identifies those checks as not evaluated. This is a detailed report of the implemented scope, not a full RISA-equivalent design package.

The section data comes from a mirrored AISC v15 workbook, not directly from AISC; see [source and limitations](public/data/AISC-SOURCE.md). The hash identifies the mirror only; official integrity and redistribution terms have not been independently verified. Compare properties against the official source before use. The user-supplied references and comparison caveats are summarized in [reference cases](docs/reference-cases.md). The input/report research and source-access limits are documented in [professional beam workflow](docs/professional-beam-workflow.md).

The updated calculator requires sign-in before running an analysis. Firebase sign-in and 14-day trial code are implemented but these updates are not yet deployed or verified with a live project; Firebase must be connected before sign-in and analysis can work. See [Firebase setup](docs/firebase-setup.md). Sign-in collects a user's name, company and discovery source; project name and preparer are saved with the authenticated account. Owners can review and export collected records after configuring the private [owner data access](docs/admin-data.md). Stripe, pricing and paid subscriptions are not configured; see [Stripe setup requirements](docs/stripe-setup.md). The visual input guide and synchronized diagrams are available in the calculator.

For Vercel, the repository's `vercel.json` runs `npm run build` and publishes `dist/`. The build copies the site and its data into that directory. Set the Vercel project root to the repository root; project-level build or output overrides must agree with these settings.

The 4:1 preset (selected by default) and custom safety-factor load comparisons are user-proposed illustrations only, not verified code combinations or member-capacity checks. Service diagrams and deflections remain on the service load. See [scaffold factors and limitations](docs/scaffold-factors.md) before interpreting them.

The supported beam's visual input guide links drawing labels to fields. Its response diagrams use a synchronized cursor, labeled extrema and zero shear, and a downward-positive reduced-EI deflection plot. Curves connect sampled response values; the report uses vector diagrams. The optional safety-factor comparison is separate from the service diagrams. Additional arrangements and full member and scaffold-capacity checks remain unimplemented.
