# Scafmetric — early beam analysis

A preliminary, bending-only, simply supported beam analysis with a landing page. Run `npm start` from this directory and visit the local server; choose Open calculator to begin; run `npm test` for the closed-form benchmarks. Requires Node.js and Python 3; no npm packages are required. The print button opens the browser print dialog, where a PDF can be saved.

The interface supports full-span downward uniform dead and live loads and optional self-weight, with a selected W shape. It displays elastic reactions, shear, moment and nominal and reduced-EI deflections. Braces are recorded as lateral restraints, not vertical supports. The standalone calculation engine additionally supports one point load, but that is not yet exposed in the interface. Calculations use Euler–Bernoulli bending; shear deformation is excluded. A 0.80 stiffness factor is the default standalone assumption, not the Direct Analysis Method. There are no AISC strength, stability, connection, bearing, deflection limit, or scaffold-specific checks, nor any wind/tie calculation. No independent OpenSees comparison has been performed. Do not use this as a construction design or an overall adequacy determination.

The section data comes from a mirrored AISC v15 workbook, not directly from AISC; see [source and limitations](public/data/AISC-SOURCE.md). The hash identifies the mirror only; official integrity and redistribution terms have not been independently verified. Compare properties against the official source before use. The user-supplied references and comparison caveats are summarized in [reference cases](docs/reference-cases.md). Further work is required for the full requested calculation and reporting scope.

The landing page describes a future free trial. Stripe, account creation, subscriptions, pricing and trial activation are not configured. See [Stripe setup requirements](docs/stripe-setup.md). The visual input guide and synchronized diagrams are available in the calculator.

For Vercel, the repository's `vercel.json` runs `npm run build` and publishes `dist/`. The build copies the site and its data into that directory. Set the Vercel project root to the repository root; project-level build or output overrides must agree with these settings.
